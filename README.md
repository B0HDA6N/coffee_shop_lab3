# [cite_start]☕ Coffee Shop App - Лабораторна робота №3 [cite: 73]

## 📝 Опис проєкту
Цей проєкт є реалізацією інтерфейсу мобільного додатка для кав'ярні на базі фреймворку **Flutter**. [cite_start]Весь макет зверстаний вручну з повним дотриманням відступів, шрифтів, кольорів та іконок, зазначених у дизайні[cite: 78]. [cite_start]Використання інструментів автоматичної конвертації було суворо заборонено та не застосовувалося[cite: 79].

## 📱 Реалізовані екрани
[cite_start]У межах роботи було створено 7 унікальних екранів [cite: 83-90, 94]:
* [cite_start]**Splash Screen**: Екран завантаження з логотипом[cite: 84, 96].
* [cite_start]**Sign In**: Екран авторизації користувача[cite: 85, 127].
* [cite_start]**Sign Up**: Екран реєстрації нового акаунту[cite: 86, 206].
* [cite_start]**Home Page**: Головний екран з бонусною системою та категоріями[cite: 87, 233].
* **Order Page**: Меню напоїв, реалізоване через сітку (Grid view).
* [cite_start]**Detail Order**: Сторінка з детальним описом та налаштуванням напою[cite: 88, 301].
* [cite_start]**Account Page**: Профіль користувача з налаштуваннями безпеки[cite: 89, 359].
